What is LLMVault?

A safe lab to practise offensive and defensive LLM security.

LLMVault is a free, open-source web application that recreates the ten risk categories from the OWASP Top 10 for LLM Applications as playable capture-the-flag challenges. Each lab is a chatbot or agent with a realistic weakness — an unsanitised output sink, a RAG index with no access control, an over-permissioned tool, a sycophantic assistant — and your goal is to exploit it to capture the flag. It runs entirely on your own machine, ships with a scored Play Mode and an optional Live Mode that points the attacks at a real local model, and requires no cloud accounts or API keys.

The OWASP LLM Top 10, as challenges

Ten core labs plus advanced and expert tiers.

LLM01

Prompt Injection

Override the system instruction and make the assistant ignore its guardrail.

LLM02

Sensitive Information Disclosure

Defeat a naive output filter with encoding and transformation tricks.

LLM03

Supply Chain

Inspect the AI-BOM and spot the typosquatted, unsigned dependency.

LLM04

Data & Model Poisoning

Poison a RAG knowledge base with an uploaded document; indirect prompt injection through the data layer.

LLM05

Improper Output Handling

A real DOM XSS that steals a session cookie and exfiltrates it to a collector.

LLM06

Excessive Agency

Escape an agent's unenforced tool sandbox with path traversal.

LLM07

System Prompt Leakage

Coax the model into reciting the secret hidden in its system prompt.

LLM08

Vector & Embedding Weaknesses

Abuse an ACL-blind similarity search to retrieve a confidential document.

LLM09

Misinformation

Exploit a sycophantic bot into confidently fabricating and leaking a secret.

LLM10

Unbounded Consumption

Trigger a denial-of-wallet condition that leaks internal state.

Features

Built to feel like real systems, not keyword matches.

  • Scored Play Mode with hints, ranks and badges
  • Optional Live Mode against a local model (Ollama)
  • Realistic RAG ingestion with .txt / .md upload
  • Deterministic, hash-based flag verification
  • No API keys, no cloud — runs offline
  • Docker or plain Python
  • Two themes: Neon and Phosphor (green-CRT)
  • Instructor answer key kept out of the public source

Quick start

Clone and run — then open http://127.0.0.1:5000.

git clone https://github.com/CyberSunil/LLMVault.git
cd LLMVault

# Option A — Docker
docker compose up --build

# Option B — Python
python -m venv venv && source venv/bin/activate
pip install -r requirements.txt
python app.py

⚠ Intentionally vulnerable. LLMVault is a deliberately insecure training app. Run it only on a local, trusted machine — never expose it to the public internet.
